MASSIVE ADS protocol: 1 vs 100 (Xbox 360, build v2.0.1149.0.02)

Reverse engineering status

Last reviewed: 2026-10-25.

This page is the single list of what is known, what is uncertain and what remains to be done. The chapters hold the details. The Rust implementation (crates/massive-proto) encodes the same state: every schema entry carries a layout and a meaning confidence, and the field server massived reports the observations listed under Field verification.

To do

Static analysis:

  1. Trace the update loop (0x824F3410) to bind the intervals 54, 3F and 0D to the heartbeat, statistics and impression requests (I2, U12).
  2. Read the URL parser used by CreateDownloadBinaryRequest and RequestDownloadBinary (U9).
  3. Read the HTTP status line and header parser of CMassiveSocket (U14).
  4. Follow +0x70, +0x78 and +0x90 of the locate request into the completion handler (U4).
  5. Map the error codes to message texts (U10).
